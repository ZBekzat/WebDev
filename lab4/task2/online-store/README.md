# Online Store (Lab 4 Task 2)

## Run

```bash
npm install
npm start
```

Open `http://localhost:4200`.

## Implemented

- Angular standalone app with routing
- Product model with strict TypeScript typing
- Product list + reusable product card components
- 10 products with Kaspi links
- WhatsApp + Telegram share actions using `encodeURIComponent`
- Responsive card grid
