# Album Browser (Lab 6)

Angular SPA for Web Development Lab 6 using routing, `HttpClient`, services, and Observables.

## Run

```bash
npm install
npm start
```

Open `http://localhost:4200`.

## Implemented

- Angular standalone app with Router and `router-outlet`
- Global navigation with active route highlighting
- `AlbumService` for all JSONPlaceholder API calls
- Album list, album detail, and album photos pages
- Update and delete flows with local UI updates
- Responsive photo grid and loading/empty states
