# Lab 7 - Task 2

This project demonstrates Object-Oriented Programming in Python.

## Classes

- `Animal` - base class
- `Dog` - child class of `Animal`
- `Cat` - child class of `Animal`

## OOP Concepts Used

- Inheritance
- Method overriding
- Polymorphism
- Modules

## Files

- `models.py` - contains all classes
- `main.py` - runs the program

## Example

The program creates `Dog` and `Cat` objects, stores them in a list, and
prints their information and sounds.
